# Research & Engineering Portfolio

A responsive, static personal research portfolio for Juan Felipe Quintero, designed for PhD and R&D applications.

## Preview

Open `index.html` in a browser. The site is HTML + CSS and does not require a build step. The font loads from Google Fonts when online; system fonts are used otherwise.

## Deploy to GitHub Pages

1. Sign in to GitHub as `Felipeqs13`.
2. Create a **public** repository named `Felipeqs13.github.io` (or another repository name for a project site).
3. Upload `index.html` and the `assets` folder to the repository root, then commit.
4. Go to **Settings → Pages → Build and deployment → Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. Once published, the personal site URL should be `https://felipeqs13.github.io/` (subject to GitHub Pages configuration).

## Editorial policy

Never publish internal reports, proprietary code, unpublished research data, confidential figures or lab photographs without authorization. Clearly label synthetic/illustrative visuals. Distinguish academic projects, professional work and self-directed demonstrations. Do not invent results or technical contributions.

## Structure

- `index.html` — site content
- `assets/style.css` — visual styling and responsive layout

## Updating the site

Edit text directly in `index.html`, or update the CSS in `assets/style.css`. Commit and push changes to GitHub to redeploy.
